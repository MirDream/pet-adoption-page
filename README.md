# 毛球日记 · 宠物领养主页

一个用于「元素级评论精准调整页面」实操的示例站点，单文件、无依赖，浏览器直接打开 `index.html` 即可。

## 这是什么

页面本身是一个宠物领养站点的落地页：导航、英雄区、数据条、宠物卡片、页脚。真正的重点是它**怎么被改出来的**——不是整页重写，而是选中具体元素、加一条评论、让智能体只改那一个节点。

完整的 5 条元素级标注与对应改动见 [REFINEMENT.md](REFINEMENT.md)。

## 页面结构

| 区块 | 说明 |
| --- | --- |
| 导航 | 品牌标 + 三个锚点链接，窄屏收起 |
| 英雄区 | 标题、说明、双按钮与右侧宠物视觉卡 |
| 数据条 | 三块统计，用 1px 间隙透出分隔线 |
| 宠物卡片 | 三只待领养宠物，悬停上浮 |
| 页脚 | 版权与联系方式 |

## 关键实现

- 单文件 `<style>` + 原生 JS，零依赖
- CSS 变量统一色板与圆角（`--brand` / `--line` / `--radius`）
- 英雄区用 `grid-template-columns` 两列，860px 以下切单列
- 主按钮带点击态反馈（文案与底色临时变化后复原）

## 运行与验收

```bash
# 直接双击 index.html，或
python3 -m http.server 8080
```

验收点：

1. 窗口宽度大于 860px 时英雄区左右两栏，小于则上下堆叠
2. 点击「我要领养」，按钮文案变「已为你预留表单 →」并加深底色，1.6 秒后复原
3. 鼠标悬浮宠物卡片，卡片上浮、出现阴影与品牌色边框
4. 数据条三块之间只有一条细线，不是三张分开的卡片
